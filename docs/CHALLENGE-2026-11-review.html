한 장 요약

결론은 그대로 "출품 적합"이다. 다만 안내서를 조문 단위로 다시 읽으니 지난 제안서에 없던 필수급 요구 3가지가 드러났고, 09-28 로드맵은 2주차 항목부터 밀려 있다.

  1. 모델 비종속 구조 + LLM 연결 설정 절(필수) — 구동안내서 양식 2 에 「LLM 연결 설정: 어떤 모델을 어디에 연결하는지, 교체 방법, 키 입력 위치」가 고정 항목이고, 공통 개발 규칙은 "2종 이상 모델에서 주요 기능 정상 구동 입증 권장". Mealboard 의 jobs/llm.py 는 Hailo 백엔드 하나뿐이다. → N1
  2. 재배포 제한 구성요소 명시(필수) — "오픈소스 라이선스 준수 책임은 참가팀, 재배포가 제한되는 구성요소는 구동안내서에 명시". Mealboard 의 핵심 의존성 ultralytics 는 AGPL-3.0 이며 수상 시 행안부가 복제·수정·재배포·위탁 개발까지 하게 되는 구조와 충돌 가능성이 있다. → N2
  3. 심사위원이 Pi·카메라 없이 구동할 수 있어야 한다(필수) — "구동안내서대로 구동할 수 없는 산출물은 심사 제외". 예선은 서면·AI 심사 + 구동 결과. mock 모드는 있지만 '처음부터 순서대로' 5분 안에 Windows/macOS 에서 끝나는 경로와 모의데이터 꾸러미는 아직 없다. → N3

진척: 제안 20건 중 완료 2(P1 FIFO · P2 트랙 유예) 부분 3(P7 · P12 · P18 문서 일부) 미착수 15. 이번 주(2주차) 예정이던 P3·P8·P13 은 시작 전. 남은 4.5주를 ① 제출물·필수 요건 → ② 점수 직결 보강 → ③ 선택 순으로 다시 짰다(§5).
