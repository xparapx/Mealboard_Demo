팔레트 ColorCombos #285 · Charcoal Grey, Egg Shell & Melon

색은 v4 그대로입니다. 바뀐 것은 표면 — 1.5px 차콜 외곽선을 걷어내고 라운드와 그림자로 깊이를 만듭니다. 같은 색이 두 가지 뜻을 갖지 않게 하는 규칙은 유지됩니다.

색 → 역할

  • #F5F2E9 바탕 / #FFFCF6 카드 — 채도를 뺀 에그셸. 카드가 흰색이라 바탕이 진하면 그림자가 일을 못 한다
  • #129793 틸 — 정상·충족·"살아 있음". 라이브 점, 그래프, 영양 01칸, 탄소 카드
  • #F6C445 옐로 — 위치 마커(스마일) 전용. 평면도의 크림·연두·틸 사이에서 사람만 튀어 보이게
  • #9BD7D5 아쿠아 — 보조·균형. 여유 판정 칩
  • #FF7260 멜론 — "지금 봐야 할 것". 혼잡 카드, 부족 칩, 알레르기 일치, 주요리 점, 주석 번호

v5 에서 바뀐 것

  • 외곽선 → 고도 — 전 카드의 1.5px 차콜 선을 제거하고 radius 24 + 2단 그림자. 카드가 여섯 장을 넘자 선이 화면을 잘게 썰었다
  • 영양소 막대 → 칩 한 행 — 토글 없이 항상 펼침. seaborn pastel 6색은 명도·채도·색맹 대비 검증에서 전 항목 탈락해 폐기. 색은 상태만 말한다
  • 섹션 틴트 폐기 — 카드가 흰색으로 통일되고, 탄소 카드만 틸 틴트로 남아 "다른 종류의 카드"임을 알린다
  • 알레르기 표시 · 이번 주 식단 · 배식대 도착 시각 · 평소 곡선 추가
  • 잔반 4버튼·개인 누적 제거 — 자기 신고 값을 누적해 보이면 측정한 것처럼 읽힌다

4추이 + 평소 곡선. 오늘 곡선만으로는 "지금이 평소보다 붐비는지"를 알 수 없습니다. 같은 요일 최근 N주 평균을 회색 파선으로 겹치고, 결론을 카드 머리에 한 문장으로 적습니다 — 곡선을 읽지 않아도 답이 나와야 합니다. 데이터 색은 틸 하나, 비교 기준선은 색이 아니라 선 스타일로 구분합니다. x 축은 인덱스가 아니라 '자정부터 몇 분' — 표본 수가 다른 두 곡선을 같은 시각에 얹으려면 그래야 합니다. 표본이 모자라면 최근 7일로 물러서고 범례 문구도 함께 바뀝니다./api/history?minutes=120 · /api/typical?minutes=120 (state · basis · days · rows[minute_of_day, wait_min])
5급식실 현황. 빈 평면도(벡터) 위에 익명 위치 마커만 — 영상·실사·이력이 전혀 없습니다(CLAUDE.md §2). 배치는 실제 카메라 시점 기준: 입구 = 좌측 상단(외곽선 틈 + 라벨), 통로 = 좌측변 옅은 띠, 배식대 = 하단변 좌측 끝~중앙(멜론 점선), 퇴식구 = 우측 하단, 출구 = 우측 중앙. v5 에서 외곽선을 #D5CDBA 로 낮추고 마커 테두리를 차콜에서 흰색으로 바꿔, 점이 바닥에서 떠 보이게 했습니다. 마커는 스마일입니다 — 틸 원(r 7) 위에 눈 둘과 웃는 입을 흰색으로 얹습니다. 얼굴을 그려도 저장되는 것은 여전히 0~1 좌표 두 개뿐이라 익명성은 그대로입니다./api/positions state · n · points[{x,y} 0~1] — 파일 하나를 덮어쓸 뿐 이력 없음
6메뉴 + 알레르기. 2열 격자를 한 줄 리스트로 바꿨습니다 — 번호가 붙으면 2열은 좁습니다. 이름은 왼쪽, 번호는 오른쪽 끝 정렬이라 번호만 세로로 훑을 수 있습니다. NEIS 의 DDISH_NM 은 돼지고기김치찜 (5.6.10.13) 형태로 번호를 붙여 보내므로 이 값은 이미 meal.json 안에 있었고 화면에서 버려지고 있었습니다. 내 항목과 겹치는 메뉴는 행 전체를 옅은 멜론으로 덮고 해당 번호만 굵은 멜론 — 테두리 대신 면으로 처리해 카드 안에 선이 늘지 않습니다. 선택은 브라우저에만 저장합니다.today.menu[] 의 꼬리 숫자 · localStorage mb_allergy
7영양 요약 3칸. 법정 기준의 구조(양·비율·충족)를 그대로 3칸으로. 색은 칸의 정체성(01 틸 · 02 아쿠아 · 03 멜론 틴트), 상태는 우상단 플래그 — 둘을 섞지 않습니다.energy_pct · macro_ratio_ok · mar
8영양소 칩. v4 의 접힌 막대 6개를 항상 펼친 칩 한 행으로 바꿨습니다. 칩은 권장섭취량(RNI) 대비 과부족만 말합니다. ±% 의 부호가 곧 색입니다 — 0 이상은 푸른 계열, 음수는 붉은 계열 그라데이션. 그중 평균필요량(EAR)에도 못 미치는 칸(fetch_neis.py 의 band)만 멜론 외곽선과 "부족" 글자를 더해, 3칸의 "부족 N" 플래그가 가리키는 대상을 분명히 합니다. 색만으로 판정하지 않도록 ±% 와 글자를 함께 둡니다.micro[].pct · band (부족 = EAR 미만)
9이번 주 식단. fetch_neis.py 는 처음부터 월~금 5일치를 week[] 로 저장해 왔는데 화면은 today 만 썼습니다. 서버 변경 없이 카드 하나로 답이 됩니다. 요일이 컬럼이고 요일마다 색이 다릅니다 — 월 아쿠아 · 화 에그셸 · 수 멜론 · 목 페리윙클 · 금 세이지. 앞의 둘은 브랜드 색을 그대로 쓰고 나머지 셋을 최대한 벌렸습니다(전체쌍 정상시야 최악 ΔE 10.7, 본문 대비 7.2:1 이상). 색맹에서는 갈리지 않는 쌍이 남습니다 — 다섯 색을 같은 명도대에 놓으면 원리상 그렇습니다. 그래서 칩마다 요일 글자와 날짜를 찍어 색이 유일한 단서가 되지 않게 합니다. 오늘만 램프 밖으로 빠져 차콜입니다. 메뉴 이름은 overflow-wrap:anywhere 로 띄어쓰기 없는 긴 이름(친환경토마코펜라이스)이 칩 밖으로 나가지 않게 하고 세 줄에서 말줄임합니다.week[] · week_avg
